# 档案元数据核对台

`sologsb-1020` 是一个用于口述史与手稿档案元数据比对的本地优先前端工作台，使用 Qwik、TypeScript 和 Qwik UI 构建。

## 功能

- 导入 A / B 两组记录，支持 JSON 数组、制表符和竖线分隔文本。
- 按标题、日期、人物、地点和编号加权匹配，显示综合分数与判断依据。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略，支持批量操作。
- 合并时逐字段并排展示 A / B 来源，每个冲突字段可单独保留或拼接。
- 保存原始记录、字段来源选择、合并结果和忽略动作，形成完整审计轨迹。
- 支持撤销重做、离线 localStorage 保存和 JSON 核对包导出。
- 大量记录采用分批窗口渲染，匹配计算限制每条记录的候选数，避免一次挂载全部行。

## 技术栈

- Qwik 1.20
- TypeScript 5.9
- Qwik UI Headless `@qwik-ui/headless`
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

静态产物输出到 `dist/`。

## 测试

## Docker

```bash
docker build -t sologsb-1020 .
docker run --rm -p 10020:80 sologsb-1020
```

nginx 在容器内监听 `80`，宿主端口 `10020` 由根端口表或运行命令映射。

## 数据说明

记录和审计轨迹保存在当前浏览器。导入新记录后自动重新计算候选匹配，但不会自动确认或覆盖任何字段；已确认、已忽略与已合并的匹配会按记录对原样保留。

## 跨系统对账（中心库离线修订包）

- 顶栏「接收修订包」导入中心库下发的 JSON 修订包（`packageId` / `baseVersion` / `items[]`），弹窗内可载入基准一致与基准偏离两个示例包。
- 修订项**逐字段合入，绝不整包覆盖**：本地不存在的记录自动新增（归入「中心库新增」C 组，字段来源标记为修订包）；与本地逐项一致的记为 unchanged；无确认关联的删除直接生效。
- 同名记录任一字段与本地核对结论不一致时挂起到「未决对账」，核对员对每个字段选择**采用修订包 / 保留本地 / 拼接**；字段未选齐时入库按钮禁用，未决项不能入库。删除指令若关联已确认或已合并匹配，同样必须裁决（按包删除仅断开建议匹配，确认/合并事实保留）。
- 字段最终来源写入记录的 `fieldOrigins`（本地 / 修订包 / 核对员），每个动作（接收、挂起、重投去重、裁决入库、基准对齐）都进入审计轨迹。
- **中断重投幂等**：同一份包（相同 `packageId`）可重复投递，已处理项按「记录编号 + 操作类型」去重，不重复应用；未决冲突会刷新两侧快照但保留核对员已做的选择。投递进度见「修订包投递台账」。
- **基准版本偏离**：包的 `baseVersion` 与本地 `repoVersion` 不一致时，横幅与台账红标警示，未决结果照常显示并标注包基准；包内全部冲突入库后本地基准对齐（只前进不回退）。
- 导出的核对包包含修订包、投递台账、未决冲突与字段来源，便于跨系统留痕。
