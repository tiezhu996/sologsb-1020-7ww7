# 档案元数据核对台

`sologsb-1020` 是一个用于口述史与手稿档案元数据比对的本地优先前端工作台，使用 Qwik、TypeScript 和 Qwik UI 构建。

## 功能

- 导入 A / B 两组记录，支持 JSON 数组、制表符和竖线分隔文本。
- 按标题、日期、人物、地点和编号加权匹配，显示综合分数与判断依据。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略，支持批量操作。
- 合并时逐字段并排展示 A / B 来源，每个冲突字段可单独保留或拼接。
- 保存原始记录、字段来源选择、合并结果和忽略动作，形成完整审计轨迹。
- 支持撤销重做、离线 localStorage 保存和 JSON 核对包导出。
- 大量记录采用分批窗口渲染，匹配计算限制每条记录的候选数，避免一次挂载全部行。

## 技术栈

- Qwik 1.20
- TypeScript 5.9
- Qwik UI Headless `@qwik-ui/headless`
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

静态产物输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1020 .
docker run --rm -p 10020:80 sologsb-1020
```

nginx 在容器内监听 `80`，宿主端口 `10020` 由根端口表或运行命令映射。

## 数据说明

记录和审计轨迹保存在当前浏览器。导入新记录后自动重新计算候选匹配，但不会自动确认或覆盖任何字段。

## 跨系统对账（中心库离线修订包）

- **逐项入账、字段带来源**：修订包逐条目投递（非整包覆盖），入库只改包携带且核对员选定的字段，每个字段写入 `provenance`（本地 / 中心库 / 拼接、包编号、核对员、时间）。
- **本地操作记录不被冲掉**：重新匹配时已确认 / 已忽略 / 已合并的匹配保持原状态；逐字段合并结论与审计轨迹独立保存，修订入库不覆盖。
- **同名记录两边不一致 → 核对员选择**：按编号优先、标题兜底匹配本地同名记录；冲突项以「本地现值 / 中心库基准 / 中心库修订」三方并排展示，逐字段选择保留本地、采用修订或拼接；存在未决结论时入库闸门关闭。
- **可中断、可重新投递、幂等**：投递台账记录包校验和、投递次数与已处理条目键；发送中断后同一份包重投自动续传，已处理项跳过，同包同内容不产生重复结论，已入库包重投整包跳过、不重复新增记录。
- **基准版本偏离显示**：包 `baselineVersion` ≠ 本地库基准，或条目 `baseline` 字段值与本地现值不一致（本地已做过核对处理）时，结论标记“基准偏离”并在队列中置顶、高亮，字段级偏离逐字段标红；偏离包中的无差异项和新增项同样挂起，须核对员确认后才能入库。
- 投递与对账支持撤销/重做，全部状态（含投递台账、未决结论）离线保存在 localStorage。

内置两个示例包（接收修订包 → 载入示例包）：`CR-2026-09-V3`（基准一致，含冲突 / 无差异 / 新增 / 字段级偏离）与 `CR-2026-10-V2REPLAY`（基于旧基准 v2，整包基准偏离）。勾选“处理到一半模拟中断”可演示重投续传。
